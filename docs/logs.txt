Put together directory first target: memalloc (short for memory allocators).

Has no code in it yet but planned out which allocation strategies to implement in the future.

May involve some extensive research, specifically regarding C++ standard library and algorithms.

I put together a base MemoryAllocator class that all allocators will extend. However, I plan to employ certain software design patterns like adapter, decorator, and others later on.

For example, making a ThreadSafeAllocator that can add to what allocator is used but essentially makes it thread safe without repeating this for every allocator class.

With the MemoryAllocator base class, taking advantage of these design patterns will become a reality.

I'm going to take a look at my game engine book and various online/text resources a little more to get a better grasp of low-level memory management.
